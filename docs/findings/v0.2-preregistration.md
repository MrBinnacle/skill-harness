## Gate fields

| Field | Value |
|---|---|
| Pending decision | Which skills in the operator's live Claude Code setup (~75 skills) earn their slot — per-skill keep/cut, the recurring Gate-2 decision this harness exists to serve. First subject skill: one from that live library, chosen for having a real task domain with mechanically checkable outcomes. |
| Primary contrast | Full vs Null, whole-skill, paired per task. Full = agent runs with the skill installed; Null = identical agent, config, and task without it. One primary test per skill (multiplicity family = 1). **Null-arm definition (POC-established 2026-07-09):** Null is the STOCK agent environment — Claude Code's built-in skills remain present in both arms; the arms differ by exactly the one skill under test. The contrast therefore answers "does adding this skill to a normal setup change outcomes," not "skills vs no skills." |
| Task source | Real tasks from the skill's actual domain, sampled from the operator's genuine workload — NOT tasks selected because the skill addresses them (findings doc §3). Task list frozen before any Full/Null assignment. |
| Oracle set | Tracer bullet: `tests-pass` (deterministic, transcript-derived) as the single Tier-1 outcome oracle. Full run adds: lint delta, diff size, turn count, cost. Judge-graded axes only via the v0.1 calibration machinery (calibrated (judge, axis) pairs), else UNMEASURED. |
| Subject layer | Inspect (`inspect_ai`) + `inspect_swe.claude_code()` as the agentic subject. Full/Null realized via the agent's first-class `skills=` parameter. Sandbox: Docker. POC verified END-TO-END 2026-07-09 (inspect-ai 0.3.245, inspect-swe 0.2.65, Windows host, Debian bookworm sandbox, Claude Code agent, OpenRouter-bridged model): (a) agent completes a file-creation task scored from sandbox state, accuracy 1.0; (b) paired Full/Null via `skills=` — Full arm's agent enumerates the injected skill, Null arm's does not, 1.0/1.0. Operational facts: host venv needs `openai` AND `anthropic` (bridge deps, errors are silent-ish without debug=True); outcome oracles MUST resolve paths against the agent's pinned `cwd` (default `/root`), never the sandbox default. Fallback if the sandboxed path develops ≥1 session of friction: the isolated-config-root local runner from the source research arc. |
| Harness pin | Recorded per trial, identical across arms, or the trial is inadmissible: inspect-ai version, inspect-swe version, `claude_code(version=)` pinned to an exact agent version (never `auto`), model id, sandbox image digest, `env`, `disallowed_tools`. Rationale: harness-induced variance on identical weights reaches 10–20pp — larger than most skill effects. |
| Differentiation vs field | Checked 2026-07-09. Anthropic prescribes Full-vs-Null but ships no runner; `adewale/skill-eval-harness` ships paired lift but with uncalibrated user-supplied judges and flags (not refusals) on weak evidence. This run produces: admissibility-gated verdicts in the append-only evidence store with UNMEASURED as a first-class outcome, and harness-pin admissibility no existing tool enforces. Interop, not rebuild: the subject layer IS Inspect. |
| MDE + sizing | OPEN — tracer bullet first measures per-(task, arm) noise on the agentic subject (prior from source arc: CV ≈ 17.6% single-turn-harness; agentic-sandbox CV unknown). Sizing computed from measured CV before the sized run; state n × k and the minimum detectable effect here when known. |
| Stopping rule | Beta-Binomial sequential bounds (`ablation/stopping.py`), N_max stated at sizing time. Tracer bullet: fixed micro-k, exploratory-only, no verdict claims. |
| Leak audit | Before any paid trial: grep every task artifact visible to the subject for (a) the expected fix/answer strings, (b) the skill's name and distinctive vocabulary. Failing-test files stripped to assertion-minimum — no docstrings stating the fix (oracle-authoring rule, findings doc §4). Post-run: transcript grep confirming the subject never read an answer-bearing artifact. |
| Budget | Tracer bullet ≤ $10 total, per-trial cap enforced by the existing cost-ledger discipline. Sized run budgeted at sizing time; hard tripwire recorded here before launch. |

## Tracer-bullet scope (the build this draft licenses)

One skill, one task, Full + Null, k small, `tests-pass` oracle, harness pin recorded,
result written to the evidence store through the existing admissibility machinery. The
deliverable is the working end-to-end path and a noise estimate — explicitly NOT a
keep/cut verdict on the subject skill.
