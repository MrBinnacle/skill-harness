Does this skill help?

>>> METHOD

It runs a task twice. Once with the skill, once without it. Then it compares the two runs.

>>> WHAT IT REFUSES

When the difference is too small to call, or the sample too thin, it says so. It does not fill the gap with a number.

One skill, measured

Each run of the task is one try. The same task runs eight times with the skill and eight times without, and the two sets are compared. The task hides a false fact on purpose, so a try either catches it or misses it.
